##  استاد راهنما: سید مصطفی هاشمی مطلق  

---

## 📌 مقدمه

این پروژه با هدف شناسایی و تشخیص افتادن افراد در محیط‌های مختلف پیاده‌سازی شده است. با توجه به اهمیت امنیت و مراقبت از سالمندان و افراد آسیب‌پذیر، شناسایی افتادن به‌صورت بلادرنگ می‌تواند نقش مهمی در نجات جان افراد و پیشگیری از حوادث ایفا کند.

---

## ⚙️ تکنولوژی‌ها و ابزارها

- YOLOv8n-pose برای استخراج نقاط کلیدی بدن
- LSTM برای یادگیری رفتارهای زمانی بدن
- کتابخانه‌های مورد استفاده:
  - `Ultralytics` (برای YOLO)
  - `OpenCV` (برای پردازش تصویر)
  - `PyTorch` (برای ساخت و آموزش مدل)
  - `NumPy`, `sklearn`

---

## 🧠 ساختار کلی پروژه

1. استخراج keypoints از ویدیوها با استفاده از مدل YOLOv8n-pose
2. استخراج ویژگی‌های حرکتی (زاویه تنه، طول بدن، فاصله سر تا لگن)
3. آموزش مدل LSTM برای شناسایی افتادن
4. اجرای سیستم به‌صورت لایو (وبکم) یا روی فایل‌های ویدیویی
5. ذخیره مدل نهایی برای استفاده مجدد

---

## 🛠 مراحل اجرا

### 1. نصب پیش‌نیازها

```bash
pip install -r requirements.txt


2. ساخت ویدیو از فریم‌ها (در صورت نیاز)

python make_multiple_videos.py


3. استخراج keypoints از ویدیوها

python extract_keypoints_batch.py


4. تولید توالی ویژگی‌ها برای یادگیری

python generate_sequences.py


5. آموزش مدل LSTM

python train_fall_lstm.py


6. اجرای مدل (real-time یا mp4)

# برای وبکم:
use_webcam = True
python run_fall_detection_lstm.py

# برای فایل ویدیو:
use_webcam = False
video_path = "videos/fall_1.mp4"
python run_fall_detection_lstm.py


عملکرد و دقت
با حدود 70 ویدیوی آموزشی (۳۰ افتادن و ۴۰ رفتار عادی)، مدل توانست به دقتی حدود 84٪ دست یابد. با افزایش تنوع و کیفیت ویدیوها، این دقت به شکل چشم‌گیری قابل افزایش است.


💡 نکات مهم
پروژه هم روی CPU و هم روی GPU قابل اجراست.

در صورتی که CUDA به‌درستی نصب و Torch با پشتیبانی GPU نصب شده باشد، از GPU استفاده می‌شود.

اگر GPU موجود نباشد، پروژه به‌صورت خودکار از CPU استفاده می‌کند.

کیفیت ویدیوها، زاویه دوربین (از روبه‌رو یا بالا) و رزولوشن تأثیر مستقیمی بر عملکرد دارند.
