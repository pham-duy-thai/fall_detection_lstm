# Backend

Backend API cho hệ thống phát hiện té ngã. Phần này sẽ nhận sự kiện từ module AI,
lưu lịch sử và cung cấp dữ liệu cho frontend/webapp.

## Dự kiến

- `main.py`: FastAPI application
- `requirements.txt`: dependency riêng của backend
- `data/`: dữ liệu runtime của backend (không dùng chung với dữ liệu train)
